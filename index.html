What is zozScript?

zozScript is a general-purpose language made for the modern feature age. Legacy languages force you to write thousands of lines of code or download massive external packages just to do simple tasks. zozScript fixes this by making powerful features like native AI requests and permanent file storage part of the core language syntax rules.

It skips all the old academic boilerplate code. Your files transpile into clean, optimized code strings that run directly on Google's hyper-fast V8 engine. You get clean syntax without losing any hardware speed.

Example Code: Advanced Calculator

Create a file called calc.zoz in Notepad and paste this code:

console.print("=========================================")
console.print(" zozScript Power Calc ")
console.print("=========================================")

let running = true
while running {
    console.print("-----------------------------------------")
    let num1 = number(console.input("Enter first number: "))
    let op = console.input("Choose operator (+, -, *, /) or type 'exit': ")
    
    if op == "exit" {
        running = false
    }
    
    if running {
        let num2 = number(console.input("Enter second number: "))
        
        if op == "+" { console.print("Result: " + string(num1 + num2)) }
        if op == "-" { console.print("Result: " + string(num1 - num2)) }
        if op == "*" { console.print("Result: " + string(num1 * num2)) }
        if op == "/" { console.print("Result: " + string(num1 / num2)) }
    }
}

console.print("Calculator closed cleanly! 🎉")

How to run it

  1. Put zoz.exe in your project folder.
  2. Open your standard command line (CMD).
  3. Type this command:

zoz calc.zoz
